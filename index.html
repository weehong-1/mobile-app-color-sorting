Icon sorter

Sort the app icons on a home screen screenshot by colour. Everything happens in this tab — your screenshot is never uploaded anywhere.

1. Choose a screenshot

Or drag one here. A home screen screenshot from a phone works best.

2. Check the grid

Orange squares are the icons that were found. Select a square to include or exclude it. If the grid is off, adjust it below.

Adjust the grid

Moving a slider finds the icons again, which clears any squares you selected.

3. Choose how to sort

Colour palette

Colours are grouped into families by hue, and each family runs pale to deep. Only the families change the order; the steps name the colours.
